This log records every non-trivial decision of the `INV_SMALL_CASH` migration and every deviation from a literal reading of the request: what was decided, the alternatives, why, and the risks. It is the single source of "why": code and the other documents cite its `D-xx` ids instead of restating rationale, and every risk it states about Oracle runtime, binding or SQL behaviour is UNVERIFIED, because nothing in this run executes against Oracle.
